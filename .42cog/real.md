## 日程

- **考试：2026-10-24（周六）14:30—18:30**，软件设计师第一批机考——**已凭准考证核实**（10-20 用户确认）
- 备考窗口：**只剩 4 个自然日**（10-20 ~ 10-23），在职备考，**每日实际投入 3~4 小时**（用户确认）
- 交付形态：走进考场、两科一次通过
- 谁在等：用户自己（职称 / 职业资格用途）

## 底线红线

- **两科必须同一次通过**（基础知识 ≥45/75 且 应用技术 ≥45/75），软考不滚存——任何一科不过，下次全部重来
- 不可对外说的：无
- 必须保住的最低标准（＝验证红线）：见 `intent.md` 的「作品区」小节

## 资源现实

- 模型 / 账号 / 额度：AI 全程陪跑（本会话及后续）
- 硬件 / 网络：用户自己的电脑；考试为**机考**（机房，非纸笔——演练要按机考节奏练）
- 人手：考生一人 + AI；每日 3~4 小时（标准方案：1 场摸底 + 2~3 场整场演练 + 归因补弱循环，另每日 ≤30 分钟教材速查兜底）

## 使用者现实

- **非科班**（2026-10-20 用户自述修正）：非计算机专业，**8 年程序员**（近 2 年 vibe coding / AI 辅助），**熟悉前端和 Python、以及 AI**；C++ 与 Java 均不熟、手写代码能力已生疏——下午题第 4 题（C 算法填空）与第 5/6 题（C++/Java 二选一）**不再是预想的优势项**，第 5/6 需速成一门
- 实战仍在的部分：软件工程流程、面向对象概念（前端 class/TS 类型系统与 Java 语法家族较近——**间接利好 Java 路线**）、数据库使用、代码阅读（Python 背景读 C 不难，题 4 保底可略乐观）；科班理论题（编译/文法/自动机等）仍按弱项对待
- 弱项预判（待 mock-01 实测覆盖）：计算机组成与体系结构、存储与校验码、网络与子网划分、PV 操作、数学、知识产权、专业英语，**外加程序语言理论与数据结构理论辨析**
- 机考界面需提前熟悉（官方有模拟练习平台）——10-23 前至少过一遍
