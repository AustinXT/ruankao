上午 · 基础知识（75 空 × 1 分）

A1　软件工程11~13 分熟·主力

  • 开发模型辨析：瀑布（需求明确）· 原型（需求模糊）· 增量（分期交付）· 螺旋（风险驱动）· 敏捷 Scrum/XP · RUP（初始→精化→构建→移交）
  • McCabe 环路复杂度 V = E−N+2（= 判定节点数 + 1）
  • 测试阶段序：单元→集成→确认→系统→验收；集成策略：自顶向下（需桩模块）/ 自底向上（需驱动模块）
  • 白盒覆盖由弱到强：语句 < 判定 < 条件 < 判定/条件 < 路径；黑盒：等价类 · 边界值 · 因果图 · 错误推测
  • 维护四类：改正性 · 适应性 · 完善性（占比最大） · 预防性
  • CMM 五级：初始→可重复→已定义→已管理→优化（CMMI 同口径）
  • ISO 9126 六特性：功能性 · 可靠性 · 易用性 · 效率 · 维护性 · 可移植性
  • 内聚（高好）：偶然<逻辑<时间<过程<通信<顺序<功能；耦合（低好）：非直接<数据<标记<控制<公共<内容
  • 关键路径 = 最长路径（决定工期）；总时差 = 最晚开始 − 最早开始；甘特图看并行
  • 需求分类：功能 vs 非功能（性能/安全/质量属性）；需求验证靠评审
  • 风险管理：识别→估计→评价→应对；风险暴露 = 概率 × 损失

A2　面向对象 + 设计模式9~11 分熟·主力

  • 多态 = 重写 + 动态绑定（运行期）；重载 = 编译期，二者不同
  • OO 原则：开闭（扩展开放/修改关闭）· 里氏替换 · 依赖倒置（面向接口）· 单一职责 · 组合复用 · 迪米特
  • UML 静态图：类/对象/构件/部署；动态图：用例/顺序/通信/状态/活动
  • 类关系耦合递增：依赖 < 关联 < 聚合（空心菱形）< 组合（实心菱形）< 泛化/实现
  • 创建型 5：单例 · 工厂方法 · 抽象工厂 · 建造者 · 原型
  • 结构型 7：适配器 · 桥接 · 组合 · 装饰器 · 外观 · 享元 · 代理
  • 行为型 11：观察者 · 策略 · 命令 · 模板方法 · 状态 · 责任链 · 中介者 · 备忘录 · 访问者 · 迭代器 · 解释器
  • 情景→模式：唯一实例=单例；算法族互换=策略；一对多通知=观察者；接口转换=适配器；动态加职责=装饰；骨架固定子类实现=模板方法；请求排队/撤销=命令；控制访问=代理；树形部分-整体=组合
  • 顺序图：生命线 · 激活条 · 消息编号；状态图：事件[守卫]/动作；活动图：分叉/汇合（并发）

A3　数据结构与算法8~10 分半·理论辨析补强

  • 栈应用：表达式求值 · 函数调用 · 递归；n 个元素出栈序列数 = 卡特兰数
  • 循环队列：队满判 (rear+1)%n == front（牺牲一格）；队空 front==rear
  • 二叉树性质：n0 = n2 + 1；第 i 层 ≤ 2^(i−1)；k 层满树共 2^k − 1 节点
  • 遍历：先/中/后序 + 层序；由「中序 + 先序（或后序）」唯一重建二叉树
  • 哈夫曼树：带权路径 WPL 最小 · 无度为 1 的节点（n 叶共 2n−1 节点）；哈夫曼编码 = 前缀码
  • 二叉排序树中序有序；AVL 失衡旋转 LL/RR/LR/RL；m 阶 B 树概念辨析
  • 图存储：邻接矩阵 O(n²) · 邻接表 O(n+e)；DFS 借栈 · BFS 借队列
  • MST：Prim（稠密图）· Kruskal（排序边+并查集）；最短路：Dijkstra 单源（贪心）· Floyd 全源 O(n³)
  • 拓扑排序从入度 0 出发；AOV 网（活动排序）vs AOE 网（求关键路径）
  • 排序复杂度：O(n²) 档 = 冒泡/直接插入/简单选择；O(nlogn) 档 = 快排（最坏 O(n²)）· 堆排 · 归并；基数 O(d(n+r))；稳定 = 冒泡·插入·归并·基数
  • 折半查找：有序 + 顺序存储，最多比较 ⌊log₂n⌋+1 次
  • Hash：装填因子 α=n/m 越大冲突越多；冲突处理 = 开放定址 · 链地址
  • 策略特征：分治=分解-求解-合并；贪心=局部最优不回头；DP=最优子结构+重叠子问题+填表；回溯=试探-撤销；分支限界=队列式搜索

A4　数据库系统7~8 分熟·主力

  • 三级模式：外模式（用户视图）· 模式（全局逻辑）· 内模式（物理）；两级映像保数据独立性
  • ER→关系：1:1 并入任一端；1:n 并入 n 端加外键；m:n 独立成表（两端主键 + 联系属性）
  • 关系代数：σ 选行 · π 选列 · ⋈ 连接 · ÷ 除（象集全包含）
  • 键：候选键 = 无冗余的极小属性集；主键从候选键中选；外键参照他表主键
  • 范式：1NF 属性原子；2NF 消非主属性对键的部分依赖；3NF 消传递依赖；BCNF 所有决定因素都是候选键
  • SQL：WHERE 过滤行 · GROUP BY 分组 · HAVING 过滤组 · ORDER BY 排序；子查询 IN/EXISTS
  • 事务 ACID：原子 · 一致 · 隔离 · 持久
  • 并发三问题：丢失修改 · 脏读 · 不可重复读；S 锁共享（读）X 锁排他（写）；两阶段锁协议保证可串行化
  • 概念题：数据仓库（面向主题、不更新）· 分布式数据库透明性 · NoSQL/反范式

A5　程序设计语言基础5~6 分弱·科班理论

  • 编译六阶段：词法→语法→语义→中间代码→优化→目标代码；解释逐句执行、不生成目标代码
  • 文法推导（最左/最右）与语法树；文法二义性
  • DFA/NFA 状态转移图辨析；正则式与自动机等价
  • 传值/传址计算题：传值拷贝不改实参；传址（指针/引用）可改
  • 函数调用栈：局部变量 · 参数传递 · 返回地址；递归深度 = 栈深度

A6　计算机组成与体系结构5~7 分弱·记公式

  • 补码范围 −2^(n−1) ~ 2^(n−1)−1；0 表示唯一；移码用于阶码比较
  • 浮点：阶码定范围 · 尾数定精度；IEEE 754 单精度 = 1+8+23 位
  • 流水线：周期 = 最长段 Δt；n 条指令总时间 = (k+n−1)Δt；吞吐率 = n/总时间；加速比 = nk/(k+n−1)
  • Cache：平均访问时间 = h·tc + (1−h)·tm；映射：直接/全相联/组相联；写直达/写回
  • 可靠性：串联 R=R1×R2×…；并联 R = 1−∏(1−Ri)
  • 校验码：海明码 2^r ≥ n+r+1（纠 1 检 2）；CRC 模 2 除生成多项式；奇偶检 1 位错
  • 寻址方式：立即/直接/间接/变址/相对；CISC vs RISC（load-store 结构）
  • 磁盘存取 = 寻道 + 旋转延迟 + 传输；RAID 0 条带 · RAID 1 镜像 · RAID 5 分布式校验
  • Flynn 分类：SISD/SIMD/MISD/MIMD（向量机 = SIMD）

A7　操作系统5~6 分弱·PV 重点

  • 三态转换：就绪⇄运行；运行→阻塞（等事件/资源）；阻塞→就绪（事件发生）
  • PV：P 减 1、小于 0 则等待；V 加 1、唤醒。互斥 = P-V 夹住临界区；先申请资源信号量再申请互斥信号量（防死锁）
  • 前驱图→PV：每条前驱边对应一对 PV（前驱 V，后继 P）
  • 死锁四条件：互斥 · 占有等待 · 不剥夺 · 环路；m 进程各最多需 r 个资源，总数 ≥ m(r−1)+1 必不死锁；银行家算法找安全序列
  • 页式虚存：页表 · 缺页中断；FIFO 有 Belady 异常 · LRU 最近最久未用
  • 段式（逻辑单位、可共享）vs 页式（物理单位、对程序员透明）；段页式先段后页
  • 文件物理结构：连续 / 链接 / 索引（多级索引地址计算）；位示图（字号 = 块号/字长）
  • 作业调度：SJF 平均等待最短 · RR 响应快 · HRN = (等待+执行)/执行；磁盘调度 SSTF/SCAN（电梯）
  • Spooling：用磁盘把独占设备虚拟成共享（打印机）

A8　计算机网络4~6 分弱·子网重点

  • OSI 七层与 TCP/IP 四层映射；设备归属：集线器 L1 · 交换机 L2 · 路由器 L3
  • 子网划分：默认掩码 A/8 · B/16 · C/24；借位算子网数；主机数 = 2^h − 2；网络地址 = 主机位全 0，广播 = 全 1；CIDR /n 记法
  • TCP 面向连接可靠字节流 · UDP 无连接尽最大努力；三次握手 · 四次挥手
  • 常用端口：21 FTP · 22 SSH · 23 Telnet · 25 SMTP · 53 DNS · 80 HTTP · 110 POP3 · 443 HTTPS
  • ARP（IP→MAC）· ICMP（ping/差错报告）· DHCP 四步（Discover→Offer→Request→ACK）· DNS 递归+迭代查询
  • IPv6：128 位 · 冒分十六进制 · 零压缩写法
  • HTTPS = HTTP + TLS；邮件：发 SMTP、收 POP3/IMAP；FTP 控制连接 21 / 数据 20

A9　信息安全4~5 分半·背结论

  • 对称加密：DES · 3DES · AES · IDEA——快、密钥分发难；非对称：RSA · ECC——公钥加密、私钥解密，慢
  • 混合加密：非对称传会话密钥 + 对称加密数据（HTTPS/TLS 原理）
  • 摘要：MD5（128 位）· SHA-1（160 位）· SHA-256；单向不可逆，验证完整性
  • 数字签名：发送方私钥签 · 接收方公钥验（完整性 + 抗抵赖）；数字证书 = CA 私钥签名的公钥绑定信息
  • 攻击辨析：DDoS · 重放 · SQL 注入 · XSS · CSRF · 钓鱼/社会工程
  • 防线：防火墙（访问控制）· IDS 检测报警 · IPS 主动阻断 · VPN 隧道加密

A10　专业英语题 71~75 固定 5 分弱

  • 题型：一篇技术短文 5 空。战术：先通读定主题（软件工程/网络/数据库为主），选项代入看搭配；术语词在文中重复出现
  • 高频词群与上午考点同源：design pattern / process / database / protocol 等

A11　数学（离散/概率/逻辑）3~5 分弱·记结论+蒙

  • 命题逻辑：蕴含 → 仅「T→F」为假；德摩根律；等值演算
  • 谓词逻辑量词 ∀/∃ 与否定转换
  • 概率：条件概率 · 全概率 · 贝叶斯（先验→后验）
  • 排列组合计数；矩阵乘法可乘条件（前列=后行）
  • 战术：算得动就做，超过 2 分钟就蒙——不空题

A12　知识产权与标准化2~4 分弱·纯背

  • 著作权：人身权（署名/修改/保护完整）保护期不受限；财产权 = 作者终身 + 死后 50 年；法人作品 = 首次发表后 50 年
  • 软件著作权：开发完成自动产生 · 登记自愿；职务开发一般归单位
  • 专利：发明 20 年 · 实用新型 10 年 · 外观设计 15 年（自申请日起）；先申请原则
  • 商标：注册 10 年可无限续展
  • 标准分级：GB 强制 · GB/T 推荐；国>行>地>企；国际标准 ISO/IEC/ITU
  • 开源许可：GPL 传染性（衍生必须开源）· MIT/BSD/Apache 宽松

A13　多媒体 / 信息化 / 新技术3~5 分零散·算容量

  • 图像字节 = 水平 × 垂直 × 色深 / 8；音频每秒字节 = 采样率 × 位深 × 声道 / 8
  • 格式：JPEG 有损（DCT）· PNG 无损透明 · GIF 256 色动图 · BMP 未压缩；MPEG 视频 · MP3 音频
  • 彩色空间：RGB 显示 · YUV 视频 · CMYK 印刷 · HSV 直观描述
  • 云计算 IaaS/PaaS/SaaS；大数据 4V；物联网三层（感知/网络/应用）
  • ★ 近两次新动向：云原生（容器/微服务/DevOps）· AI 辅助开发概念条目 1~3 分——考前扫一眼概念即可

下午 · 应用技术（6 道做 5 道 × 15 分）

B1　数据流图 DFD必答 · 套路题主力

  • 图符：外部实体 = 方框（源/宿）· 加工 = 圆/圆角框（动词命名）· 数据存储 = 双横线/开口矩形（名词）· 数据流 = 箭头
  • 补实体套路：找「人 / 外部系统」；实体不能与存储直连
  • 每条数据流必须有一端是加工；加工守恒（有输入必有输出）
  • 父子图平衡：子图输入输出 = 父图对应加工的输入输出；编号对应（1 → 1.1/1.2…）
  • 答题顺序：逐句读说明圈名词 → 先实体 → 再存储 → 最后补流

B2　数据库设计必答 · 套路题主力

  • 补 ER：从需求文本划名词（实体/属性）；联系标 1:1 / 1:n / m:n
  • ER→关系三规则：m:n 独立成表；1:n 并入 n 端加外键；1:1 并入任一端
  • 主键 = 不空 + 唯一 + 极小；外键 = 引用他表主键的列
  • 补 SQL：连接条件 ON/WHERE · GROUP BY + HAVING（组级条件）· 聚合 COUNT/SUM/AVG
  • 偶考：判定关系模式最高范式并说理由（找部分/传递依赖）

B3　UML 建模必答 · 套路题主力

  • 用例图：include = 必然包含的子用例（箭头指向子用例）；extend = 条件性扩展（箭头指向基用例）
  • 类图多重度：1 · 0..1 · 1..* · *；聚合空心菱形 · 组合实心菱形
  • 顺序图：对象生命线 · 激活条 · 消息自上而下；同步 = 实心箭头，返回 = 虚线
  • 状态图：初态实心圆 · 终态双圈；事件[守卫]/动作
  • 套路：逐句对照用例描述文本 ↔ 图元素，缺什么补什么

B4　C 语言算法必答 · 保底 6~8 分

  • 先读题干「算法说明/思路」再看代码——填空答案多藏在说明里
  • 高频填空位：循环初值与边界 · 下标偏移 · 递归出口 · 交换三行 · 返回值
  • 策略识别：dp[] 数组+两层循环 = DP；每步局部择优 = 贪心；递归二分合并 = 分治；标记-试探-撤销 = 回溯
  • 复杂度填空：看循环嵌套层数（单层 n → O(n)，双层 → O(n²)，折半 → O(nlogn)）
  • 战术：读不懂整体也能填语法性的空；不恋战，保底收分

B5 / B6　面向对象程序（C++ / Java 二选一）速成 8~10 分

  • 结构：类图 + 程序骨架填空（类名 / 方法名 / 关键语句）
  • 先认设计模式（看角色结构：Context/Strategy/Observer…），按模式角色推空
  • Java 语法点：extends / implements · abstract · interface · @Override；C++：virtual · 纯虚 = 0 · : public 继承
  • 高频空：多态调用（父类引用调子类方法）· Context 调用行 · 构造方法
  • 决策（mock-01 pm 双试后定）：只速成一门，另一门不碰

考场作战卡（10-24 周六）

  • 节奏：连考 240 min；选择段 90~120 min（稳了就交，节余全给大题）；结束前 60 min 才可交卷
  • 到场：14:30 开考，13:50 前到；开考 5 min 后禁入
  • 携带：纸质准考证 + 身份证原件 + 黑色签字笔（座位上只许黑笔）；手机/手表/计算器禁带，系统自带计算器
  • 输入法：微软拼音 / 搜狗拼音 / 搜狗五笔
  • 上午战术：先稳项（软工/OO/数据库 ≈28 分池）再弱项；单题 ≤2 min；蒙答不空题
  • 下午战术：先做 B1/2/3 套路题（目标 34+/45）→ B5/6 选定门 → B4 保底；机考画图用平台绘图工具（10-23 模拟平台练，当日 17:00 关闭）
  • 过线定义：双科同次同时 ≥45；单科高不抵另一科低
  • 蒙答纪律：可以写错，不可以空着
